# ТОГУ.Расписание — Веб-приложение расписания занятий ТОГУ (Этап 1)

Современное минималистичное веб-приложение для студентов **Тихоокеанского государственного университета (ТОГУ)** на базе **React 18 + TypeScript + Vite + Tailwind CSS**.

Официальный источник структуры расписания: [https://togudv.ru/rasp/groups/](https://togudv.ru/rasp/groups/)

## Реализованный функционал (Этап 1: Основа и UI)

1. **Современный минималистичный интерфейс с тёмной темой** (а также режимами OLED Black, Светлой темой и выбором акцентного цвета).
2. **Полная адаптивность (Desktop + Mobile)**:
   - На компьютерах: фиксированная боковая панель (Sidebar), быстрый переключатель избранных групп, сводные виджеты учебного дня.
   - На смартфонах: компактная верхняя панель, горизонтальная лента дат и нижняя навигационная панель (Bottom Navigation).
3. **Раздел «Сегодня» (Главная страница)**:
   - Интерактивная лента дат с переключением дней/недель и выделением текущего дня бейджем **«Сегодня»**.
   - Виджет текущей и следующей пары с прогресс-баром, обратным отсчётом времени и встроенным демо-таймером.
   - Сводка учебного дня (количество пар, академические часы, временной диапазон, корпус).
   - Фильтрация по подгруппам (Все / 1-я / 2-я подгруппа) и типам занятий.
4. **Карточки занятий**:
   - Название предмета, номер пары (1–8) и время по звонкам ТОГУ, аудитория и крыло корпуса (`ц`, `л`, `п`, `с`, `корп. 6`, `ЭИОС`), ФИО и должность преподавателя, семантический бейдж типа занятия.
   - Автоматическое отображение **Большого обеденного перерыва (13:20 – 13:50)** и **свободных «окон»** между парами.
   - Модальное окно деталей пары с возможностью сохранения личных заметок студента (ДЗ, дедлайны).
5. **Раздел «Неделя»**:
   - Переключение между **Нечётной неделей (Числитель)** и **Чётной неделей (Знаменатель)**.
   - Переключение по дням недели (Пн–Вс) с индикацией текущего дня недели.
   - Два режима отображения: **«По дням»** и **«Вся неделя (Сетка)»**.
6. **Раздел «Группы»**:
   - Живой поиск по коду группы (`ПО(б)-31`, `ИВТ(б)-21`, `ИБ(с)-11`, `СТР(б)-22`, `ЭК(б)-32`, `АРХ(б)-21`, `ЮР(б)-12`, `ЛГ(б)-31`), коду специальности или названию профиля.
   - Фильтрация по институтам/высшим школам ТОГУ и курсу обучения (1–4 курс).
   - Добавление групп в **«Избранное»** для переключения в один клик.
7. **Раздел «Настройки»**:
   - Выбор основной группы и подгруппы по умолчанию.
   - Настройка темы (Тёмная / OLED / Светлая), акцентного цвета и компактности карточек.
   - Управление отображением «окон», большого перерыва и номеров пар.
   - Встроенный справочник расписания звонков ТОГУ и расшифровка корпусов.
8. **Демонстрационные данные**:
   - Все данные явно помечены плашкой **«ДЕМО-РЕЖИМ • ТЕСТОВЫЕ ДАННЫЕ»**.

## Как запустить проект локально

```bash
# 1. Перейдите в папку проекта
cd togu-schedule

# 2. Установите зависимости
npm install

# 3. Запустите сервер для разработки (Vite)
npm run dev

# 4. Сборка production-версии
npm run build
```
